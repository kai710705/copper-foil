## 2. 身分與存取控制

- [x] 2.2 實作 JSON 登入、POST 登出及密碼變更，Session 更新與 must_change_password 門禁；測試預設管理者須修改密碼、修改後可管理及舊密碼失效。
- [x] 2.3 統一受保護路由的即時核准／角色查驗及 CSRF，涵蓋 MVC、監控、管理與 video；測試 401、403、缺少 Token、停用後既有 Session 拒絕存取且 CAM 回歸通過。
- [x] 2.4 更新登入、註冊與密碼變更操作文件及 API 範例；逐一核對實際成功與錯誤回應，不輸出密碼雜湊。
