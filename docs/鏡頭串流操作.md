# OpenCV 鏡頭串流

1. 執行 `start.ps1`，使用已核准會員登入。
2. 開啟 `/video`。
3. 按「啟動鏡頭」，才開啟 Flask 主機的 CAM 並顯示影像。
4. 按「停止串流」釋放鏡頭；離開頁面亦會發送停止請求，無連線活動逾 20 秒後自動停止。

狀態包含：尚未啟動、正在開啟、串流中、已停止、設備錯誤。每次狀態更新會顯示鏡頭編號與擷取影格數。

預設 `CAMERA_INDEX=0`；可在啟動前設定環境變數選擇其他設備。這是伺服器鏡頭，不是瀏覽器所在電腦的鏡頭。串流只有影像，沒有音訊，也不保存錄影。

API：`GET /api/v1/camera/status`、`POST /api/v1/camera/start`、`POST /api/v1/camera/stop`、`GET /api/v1/camera/stream`。POST 需要已登入帳號及頁面的 CSRF Token。單一鏡頭僅允許一位使用者控制。

目前使用單程序內的鏡頭管理；不要為此功能啟動多個 WSGI worker。Docker 必須額外將可用的主機鏡頭裝置傳入容器；Windows Docker Desktop 的 Linux 容器不會自動取得 Windows USB 攝影機，Windows 主機直接執行 Flask 才能使用此 CAM。

離線前端資源位於 `app/static/vendor`。重新建置 Tailwind：在 `frontend` 執行 `npm ci`、`npm run build`。
